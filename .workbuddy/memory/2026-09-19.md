## GM6020 速度环调参进展（空载）

- 用户已自行把参数调到：Kp=60 / Ki=2 / Kd=0 / MAX_OUT=25000 / MAX_IOUT=20000 / FF=0（Motor.h）。
- 实测：目标 200 时空载波动 ±7~8 rpm；目标 150 时最大误差 ±10 rpm（≈6.7%）。
- ⚠️ 判读教训：SerialPlot 纵轴**自动缩放**，±8rpm 的波动会被拉满整个图高，视觉上像剧烈振荡。看截图估算抖幅前必须先确认纵轴量程，否则极易高估一个数量级（曾误判为 ±40）。以用户现场读数为准。
- 给出的诊断两步法（区分误差性质，决定还能不能靠调参改善）：
  1. **静止基线**：发 `0` 指令，看 actual 通道抖不抖。若静止时就在 ±10 抖 → 反馈/电机固有纹波，PID 无责，再调无效。
  2. **输出平稳度**：运转时看第三个通道 pid_output。pid_output 剧烈抖 → 环路在振，降 Kp 有效；pid_output 平稳但转速抖 → 机械侧齿槽纹波，PID 无能为力。
- 误差形态区分：actual 中心线持续偏离 target（如稳定在 140 够不到 150）= 静差，靠积分/前馈补；围绕 target 对称抖动 = 纹波，靠降 Kp 或增大惯量。
- 下一步建议顺序：Kp 60→40；启用 YAW_SPEED_FF=60.0f（前馈改善跟踪，但不减纹波）；带载后惯量变大通常自然收窄；仍不达标才换电流模式(0x1FE)。
- 未改任何代码（用户明确要求只给操作步骤）。
