# 2026-09-09

## Yaw 一顿一顿排查 + 正弦切换功能

### 项目实际状态（与 AGENTS.md 不一致）
- 实际硬件是 **M3508 + C620**（CAN_receive.h 顶部注释），不是 AGENTS.md 里的 GM6020
- 单 CAN1（PD0/PD1），反馈 ID 0x201=Yaw(ID=1)、0x202=水平(ID=2)
- 单 FreeRTOS 都不用（TIM6 1ms tick + 主循环 bare），是简化版导轨项目
- AGENTS.md 是从步兵模板照搬过来的，不能直接套用

### 用户反馈的问题
- Yaw "一顿一顿"
- 三嫌疑（按可能性）：
  1. CAN_cmd_both 忽略 HAL_CAN_AddTxMessage 返回值 → 邮箱满/总线出错时电流帧静默丢弃
  2. 速度环单环 + KP 太高 + Ki=0 → 低速震荡
  3. 反馈丢帧用了过期 speed_rpm
- 用户把 KP 调到 8、Ki 加到 0.5 后问题还在 → 大概率是 CAN 丢帧，但用户没让我加返回值检查

### 加的功能：蓝牙切 yaw 旋转模式
- 协议：`'0'` 停止、`'1'` 匀速(150rpm)、`'2'` 正弦(base=150 + amp=150·sin(2π·t/4s))
- 新增 trajectory API：
  - `yaw_spin_mode_e { YAW_SPIN_CONST, YAW_SPIN_SINE }`
  - `trajectory_set_yaw_spin(mode, base_rpm, amp_rpm, period_ms)`
  - `trajectory_get_yaw_speed()` 返回当前目标 RPM
- 新增 motor_ctrl API：
  - `motor_ctrl_t.spin_dyn` 字段（0=固定 RPM，1=动态 RPM）
  - `motor_ctrl_set_spin_dyn(motor)`
  - `motor_ctrl_update` spin 分支按 spin_dyn 决定取固定/动态值
- main.c 加 `yaw_apply_const_mode()` / `yaw_apply_sine_mode()` 两个 helper，蓝牙回调按字符分发
