# 2026-09-16

## VOFA+ 上位机接入

- 新建 `application/vofa.h` + `application/vofa.c`，实现 JustFloat（二进制 float + 00 00 80 7F 帧尾）与 FireWater（CSV 文本）两种发送方式。
- 工程现状：只有 USART1 被配置（PA9 TX / PB7 RX，115200），RX 已被蓝牙转速指令占用，TX 已被回显占用。VOFA+ 用 USB-TTL 直接并接 PA9 + 共地即可，不需要改波特率。
- 关键约束：主循环是 TIM6 1ms 节拍（1kHz 控制），阻塞式 `HAL_UART_Transmit` 在 115200 下 20 字节约 1.7ms，会拖垮控制周期 → 必须降频到 50~100Hz 发送，或改成 DMA。
- 建议观测通道：目标转速 / 反馈转速 / 输出电压 / 转矩电流。
